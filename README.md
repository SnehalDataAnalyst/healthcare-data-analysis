# healthcare-data-analysis
End-to-end data analysis project on a healthcare dataset of 19,766 patient 
records, covering data cleaning in MySQL and interactive dashboards in Power BI.

## Tools Used
- MySQL — data cleaning and exploratory analysis
- Power BI — interactive 4-page dashboard

## Dataset
- 19,766 patient records
- Columns: Name, Age, Gender, Blood Type, Medical Condition, 
  Admission Date, Discharge Date, Doctor, Hospital, 
  Insurance Provider, Billing Amount, Medication, Test Results
